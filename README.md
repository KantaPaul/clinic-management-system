# Clinic and dispensary research

This repository holds market research and a gated product plan. It does not contain an application.

No patient records are stored here. No demo data, synthetic or otherwise, has been created. Nothing in this repository is a production clinic system.

## Current decision

**No-Go for a CodeCanyon launch, and No-Go for the 12-phase clinic-plus-pharmacy build.** The owner confirmed on 23 Oct 2026 that they are not an Envato Code author. Envato is not accepting new Code author applications.

A same-day pharmacy pass replaced the earlier outpatient-only recommendation with an unapproved dispensary scope: one clinic, a prescription that does not change stock, and batch dispensing. That scope is not an approved build. See [docs/product/market-research.md](docs/product/market-research.md).

Building the Next.js application, database, and CodeCanyon package is blocked until a separate approval. The roadmap is in [docs/roadmap.md](docs/roadmap.md). The task checklist is in [.cursor/plans/clinic-management-system.plan.md](.cursor/plans/clinic-management-system.plan.md).
